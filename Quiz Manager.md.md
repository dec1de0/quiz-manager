# Quiz Manager

A Java console application for creating and taking custom quizzes. Built as a midterm project to practice OOP concepts.

## Features

**4 Question Types:**
- Regular multiple choice (4 options)
- Questions with hints
- Bonus questions (extra points)
- True/False questions

**Quiz Features:**
- Custom quiz creation (1-15 questions)
- Answer shuffling during quiz
- Point tracking and scoring
- Letter grade system (A-F)

## How to Run
```bash
javac QuizManager.java
java QuizManager
```

## Usage

1. Enter your name
2. Choose number of questions (1-15)
3. For each question:
   - Select question type
   - Enter question text
   - Provide 3 wrong options
   - Enter correct answer
   - Add hint/bonus points if needed
4. Review all questions
5. Press ENTER to start quiz
6. Answer questions and get your score!

## Grading System

- A: 90-100%
- B: 80-89%
- C: 70-79%
- D: 60-69%
- F: Below 60%
